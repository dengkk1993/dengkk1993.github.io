# 访客统计

主页正文下方显示全站总访问次数（Total views / PV）和访客数（Visitors / UV），使用[不蒜子](https://busuanzi.ibruce.info/)提供的计数服务，无需注册账号或配置密钥。

- PV 是页面访问次数，重复访问也可能增加计数；UV 按服务方的访客识别规则去重，不等于精确的自然人人数。
- 这是公开累计统计，不提供逐条访问时间、访客身份、IP 或来源地区的后台记录，也无法补回接入前未记录的历史访问。
- 统计依赖第三方服务；浏览器会向不蒜子发送统计请求。服务不可用或被浏览器拦截时，计数标签保持隐藏，正文仍可阅读。
- 全站统计按站点归集；同一域名下的其他页面也可能计入。迁移域名时，不应假定原有计数会自动迁移。

## 开关

在 `_config.yml` 中设置：

```yaml
visitor_statistics:
  enabled: true
```

改为 `false` 可同时关闭显示和第三方统计脚本。修改后需要重新构建网站。

## 部署与检查

GitHub Pages 的生产构建会启用统计。普通 `bundle exec jekyll serve` 使用开发环境，不加载计数脚本，以免将本地预览混入统计。

部署到正式域名后，打开主页，在正文底部检查 `Total views` 和 `Visitors`。数字由服务异步返回，不预填示例数据。若未显示，可在浏览器网络面板检查不蒜子脚本及计数请求是否成功。

需要本地检查生产模板时，可设置 `JEKYLL_ENV=production` 后运行 `bundle exec jekyll build`；本地浏览生产输出时应拦截第三方统计请求，使用模拟响应检查显示效果。

接入方式和 PV/UV 定义参见[官方说明](https://ibruce.info/2015/04/04/busuanzi/)。
